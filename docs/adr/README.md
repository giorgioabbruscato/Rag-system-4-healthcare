# Architecture Decision Records

This directory contains the main architecture decisions for the project.

## How to read ADRs
- `Accepted`: decision is current and preferred.
- `Proposed`: under discussion or awaiting implementation.
- `Superseded`: replaced by a newer ADR.
- `Deprecated`: kept for history, not recommended for new work.

## Writing a new ADR
Keep each ADR short and focused:
1. Context
2. Decision
3. Alternatives considered
4. Consequences
5. Status

Prefer one decision per ADR and link to related implementation docs when needed.
